# Parallax Slider Block

Create a captivating visual experience and impress your audience with a parallax slider for the WordPress Block Editor. Part of [Essential Blocks](https://github.com/EssentialBlocks).

- WordPress.org readme: [`readme.txt`](readme.txt)
- Requires WordPress 6.0+ and PHP 7.4+

## Development

```bash
git clone git@github.com:EssentialBlocks/parallax-slider-block.git
cd parallax-slider-block
git submodule update --init --recursive   # controls + lib/style-handler
npm install
npm run build    # or: npm start
```
